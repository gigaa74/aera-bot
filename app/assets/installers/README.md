# Установщик Hiddify для Windows

`Hiddify-Windows-Setup-x64.exe` предоставлен владельцем AERA 4 октября 2026 года.
Он скопирован без изменения байтов, в ходе разработки не запускался.
Версия из метаданных файла: 4.1.1+40101. Размер: 36 486 310 байт.
SHA-256: `3f6182b610168c0bb386ffea1fc7f68318d3df23c15840c8b13a3be51b080a96`.

При выборе Windows бот отправляет файл документом. Telegram file_id сохраняется
в AppSetting с ключом, содержащим ID бота и SHA-256 содержимого; следующая отправка
не загружает файл повторно. Замена файла создаёт новый ключ. Недействительный file_id
приводит к повторной загрузке. Если файла нет, пользователь получает предложение
обратиться к администратору, без перенаправления на Microsoft Store.

HTTPX-транспорт хранит большие вложения во временном файле, а не в полном буфере памяти;
локальный лимит загрузки - 50 МиБ. Сам EXE отправляется клиенту и не исполняется на VPS.
