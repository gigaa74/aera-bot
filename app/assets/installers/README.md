# Optional Windows installer

Сторонний установщик не включён в исходники. Официальные релизы: https://github.com/hiddify/hiddify-app/releases

Если нужна отправка установщика из бота, скачайте подходящий официальный x64-релиз, проверьте происхождение файла и сохраните его здесь как `Hiddify-Windows-Setup-x64.exe`. Файл исключён из Git.
