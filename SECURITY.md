# Security

Не публикуйте `.env`, Telegram/кассовые токены, SSH-ключи, production-базы, логи, кошельки клиентов и персональные ссылки подключения. Для аудита используйте отдельную тестовую базу и пустые/тестовые конфигурации.

Уязвимости передавайте владельцу приватно через @aerasuppbot, без секретов в публичных Issues. Подготовленный снимок не является заключением о полной безопасности; см. audit/STATUS.md.
