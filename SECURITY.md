# Security

Не публикуйте `.env`, токены Telegram, ключи кассы, SSH-ключи, базы пользователей и персональные ссылки подключения. Используйте `.env.example` как основу для локальной конфигурации.

Сообщения об уязвимостях: [поддержка AERA](https://t.me/AERAVP). Не прикладывайте рабочие секреты к публичным Issues.
