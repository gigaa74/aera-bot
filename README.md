# AERA VPN — current production bot

Снимок работающего приложения на **26 октября 2026 года**, синхронизированный из `/opt/aera`. Это текущая версия бота, API и его фоновых задач. Старые файлы приложений, отсутствующие в production, удалены из текущего дерева. Предыдущие версии остаются в истории Git.

**Начните аудит с [AUDIT_FOR_CLAUDE.md](AUDIT_FOR_CLAUDE.md).** Результаты предварительных проверок — [audit/STATUS.md](audit/STATUS.md). Этот снимок не объявлен полностью проверенным или свободным от ошибок.

## Состав

- `app/bot/runtime.py` — регистрация маршрутов и polling; `app/bot/customer_v2.py` — текущие клиентские сценарии.
- `app/main.py`, `app/api/` — FastAPI, обработчики платежей, выдача доступа и служебные API.
- `app/services/` — покупки, Platega/Stars, продления, пробные, партнёрка, HWID, уведомления и аналитика.
- `app/workers/run.py`, `scripts/panel_sync.py` — фоновые задачи и взаимодействие с VPN-узлами.
- `app/db/models.py`, `alembic/` — модели и текущие миграции.
- `app/assets/` — ресурсы именно из production, включая файлы, которые могут уже не использоваться активными маршрутами. Наличие ресурса не доказывает его использование.
- `tests/` — прежние регрессионные тесты плюс новые проверки `test_current_contracts.py`. Прежний набор частично устарел; подробности в отчёте.
- `audit/SOURCE_SHA256.json` — контрольные суммы 226 файлов, повторно сверенные с сервером.

## Изолированная проверка

Рекомендуется Linux и Python 3.12: модуль обновления подписок использует `fcntl`. Используйте отдельное окружение и тестовую базу без рабочих доступов.

```bash
python3.12 -m venv .venv
. .venv/bin/activate
pip install -r requirements.lock
cp .env.example .env
python -m compileall -q app scripts alembic
DATABASE_URL=sqlite+aiosqlite:///./audit-local.db python -m alembic upgrade head
python -m pytest -q tests/test_current_contracts.py
python -m pytest -q --continue-on-collection-errors
```

Последняя команда намеренно показывает полный старый baseline, включая ошибки, а не обещает зелёный результат. Существующий CI также может оставаться красным из-за устаревших тестов и накопленных замечаний Ruff. Не выключайте проверки ради зелёного статуса.

## Границы снимка

Рабочие `.env`, ключи, базы, персональные ссылки и логи исключены. Пример окружения содержит только безопасные локальные значения. Нет production-конфигурации `/etc/aera-payment/platega.json`, SSH-ключей/known_hosts из `/var/lib/aera-node-sync`, базы control-plane или зашифрованных AppSetting с настройками панелей.

Для полноценного deployment нужны отдельно предоставляемые конфигурация, Redis, панель и служебные процессы. Не запускайте polling с токеном действующего бота параллельно production. Не запускайте `scripts/panel_sync.py` при офлайн-аудите: он использует абсолютный путь к production-базе и реальные узлы.

Сайт и бот поддержки — отдельные приложения, их исходники не входят в этот репозиторий. Источник истины этого снимка — текущие файлы приложения, а не прежние тексты README или названия служб со словом preview. Наличие mock-адаптеров не означает, что production-платежи имитируются.
